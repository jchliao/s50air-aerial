## 给非乐视机型

`01` 和 `03` 里的 smali 改法是乐视特有的。换品牌请先：

1. `pm path` 找到该品牌的"桌面守护"和"信号源管理"应用
2. 反编译核对是否有同构的方法（`jumpLauncherNeedCheck` / `doSwitchPort`）
3. 包名和方法签名都可能不同，**不要照抄**

`02`（uid1000 通道）、`04`（包清单思路）、`05`（TV管家类服务的坑）的思路是通用的。
